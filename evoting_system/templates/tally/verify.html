What this page cannot show you

Nothing above (or anywhere else this system builds) can be used to work out how any individual person voted. Ballot records carry no reference to any voter or session at all — that link is destroyed the moment a ballot is recorded, before this tally is ever computed. This page only ever shows aggregate counts and mathematical commitments to those counts, never anything per-ballot.
